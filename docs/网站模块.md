# 网站配置模块

设置 → 访问网站：新增、编辑、启停或删除网站，点击保存后下次读取生效。默认保留六个新闻源。RSS/Atom 填订阅地址，普通网页读取静态 HTML 摘要；不支持登录、JavaScript 渲染或其他网站的点赞评论。

宿主模块位于 `plugin/src/host/websites/`，页面模块位于 `plugin/src/game/websites.js`。配置单独保存在插件存储目录的 `websites.json`（version 1），升级代码不会覆盖配置。空列表表示不读取任何额外网站。B站功能维持原有设置。

接入点：host/index 初始化与注册路由，sources.js 在挑选来源时读取配置，game/main.js 挂载页面。新闻工具、念新闻、旧 headless 素材预取均复用来源管道。网站仅作为外部资料，出门仍由鱼自主决定，不保证每趟访问每个站点。

新增读取方式可在 sources.js 的 fetchNews 分发处扩展；网络读取在 websites/read.js，限制公网地址、逐跳检查重定向、固定已解析的地址并限制时间和响应大小，不带 B站 Cookie。
